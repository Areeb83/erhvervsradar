    How it works, and which links are supported

    Supported links

    • EDC Erhverv lease listings, like https://www.edc.dk/erhverv/erhvervslejemaal/kontor/1552-koebenhavn-v/vester-voldgade-104/114058334/
    • Savills Denmark listings, like https://search.savills.com/dk/da/ejendomsoplysninger/dff8a9c0-92ab-4c6e-afce-f1d7e327c393

    Other links stay in your file and get a note in the Result column.

    What you get back

    The same sheet, with your own columns untouched and these added: Result, Address, Postcode, City, Property type, Size m², Rent per year, Rent per m², Source, Checked at, and a Note when something went wrong.

    Your file stays with you

    The file is read and filled in inside your browser. Only the links are sent, one at a time, and nothing is stored.

    Polite to the sites

    robots.txt is followed, there are 2 seconds between EDC pages and 5 seconds between Savills pages, and each answer is remembered for an hour so the same listing isn't fetched again and again.
